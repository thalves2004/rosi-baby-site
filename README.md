# 👶 Rosi Baby

Site oficial da **Rosi Baby**, desenvolvido para apresentar produtos artesanais e personalizados para bebês de forma simples, bonita e acessível em computadores e celulares.

## 🌐 Site

Acesse o site:

https://rosi-baby-site.thomas-alves2004.workers.dev

## 🍼 Sobre a Rosi Baby

A Rosi Baby trabalha com produtos feitos com carinho e atenção aos detalhes, incluindo:

- Naninhas personalizadas
- Roupinhas infantis
- Fraldas bordadas
- Kits para maternidade
- Kits para berço
- Enxovais
- Presentes personalizados
- Peças artesanais

Os clientes podem visualizar os produtos pelo site e entrar em contato diretamente pelo WhatsApp para solicitar informações e orçamentos.

## ✨ Funcionalidades

- 📱 Layout responsivo para celular, tablet e computador
- 🖼️ Catálogo com fotos dos produtos
- 🔎 Filtros por categoria
- 🔍 Visualização ampliada das fotos
- 💬 Integração com WhatsApp
- 📷 Links para Instagram e Facebook
- ⚡ Site estático e rápido
- 🔒 HTTPS
- ☁️ Hospedagem pela Cloudflare

## 🚀 Deploy

O projeto utiliza **Cloudflare Workers Static Assets**.

A configuração está no arquivo:

wrangler.jsonc

Para realizar o deploy manualmente:

npx wrangler deploy
